🧠 Build a Profile Settings page for a fitness and meal planning app using React (with TypeScript) and Tailwind CSS.

🎯 Requirements:
- Form UI with grouped sections and inputs.
- Fields must be validated and saved to a `user_profiles` table using Drizzle ORM.
- Assume Replit OIDC provides a session with `userId`.

📋 Fields to include:

1. Personal Info
  - Full Name (text)
  - Date of Birth (date)
  - Gender (select: Male, Female, Other)

2. Physical Metrics
  - Height (number in cm)
  - Weight (number in kg)
  - Activity Level (select: Sedentary, Lightly Active, Active, Very Active)

3. Goals
  - Fitness Goal (select: Lose Weight, Maintain, Build Muscle)
  - Target Weight (optional, number)
  - Daily Calorie Goal (optional, number)

4. Dietary Preferences
  - Diet Type (select: Vegetarian, Vegan, Keto, Paleo, Mediterranean)
  - Allergies (multi-select: Dairy, Gluten, Peanuts, Shellfish, Eggs)
  - Disliked Foods (text input or tag-based input)
  - Preferred Cuisines (multi-select: Indian, Italian, Chinese, Mexican, Japanese)
  - Meals per Day (radio: 3 meals / 3 meals + 2 snacks)
  - Intermittent Fasting (toggle)

5. Meal Timing & Cooking
  - Preferred Meal Times (time input: Breakfast, Lunch, Dinner)
  - Cooking Difficulty (select: Beginner, Intermediate, Advanced)
  - Max Cooking Time per Meal (select: <15 min, 30 min, 1 hr)
  - Available Kitchen Equipment (multi-select: Microwave, Blender, Air Fryer)

6. Wellness & Lifestyle (optional)
  - Chronic Conditions (multi-select: Diabetes, PCOS, Hypertension, None)
  - Supplements Taken (free text)
  - Stress Level (select: Low, Medium, High)
  - Sleep Duration (number, hours/night)
  - Water Intake Goal (number in liters)

🧱 Tech Stack:
- Frontend: React 18 with TypeScript, Tailwind CSS, Radix UI if needed
- Backend: Express.js with Drizzle ORM and PostgreSQL
- Session: Replit Auth (assume `userId` available from session)

🏁 Save the form data via POST `/api/profile/update` and auto-load existing values with GET `/api/profile/me`.

🎨 Bonus:
- Make the UI responsive and mobile-friendly.
- Group fields into accordions or sections with sticky section headers.
- Add inline validation and feedback.
