Recipes API

Endpoint: POST /ai/recipes/generate
Purpose: Generate a full recipe for a given dish name (no DB). Returns structured JSON (ingredients, steps, times, tips) plus a YouTube search URL for that dish.

Headers: Content-Type: application/json

Request body
{
  "dish_name": "Paneer butter masala",
  "servings": 4,
  "cuisine": "Indian",
  "dietary_prefs": ["vegetarian"],
  "exclude_ingredients": ["cashew"]
}

Fields

dish_name (string, required) – The recipe to generate.

servings (integer, optional) – Desired servings; used to tailor quantities/portioning.

cuisine (string, optional) – Hint to shape style/region (e.g., "Indian", "Italian").

dietary_prefs (string[], optional) – Tags like "vegetarian", "vegan", "gluten-free".

exclude_ingredients (string[], optional) – Ingredients to avoid (allergies, dislikes).

Response body
{
  "recipe": {
    "title": "Paneer Butter Masala",
    "summary": "Rich, tomato-butter gravy with soft paneer, North Indian style...",
    "cuisine": "Indian",
    "diet_tags": ["vegetarian"],
    "servings": 4,
    "prep_time_min": 15,
    "cook_time_min": 25,
    "total_time_min": 40,
    "ingredients": [
      { "name": "Paneer", "qty_text": "200 g" },
      { "name": "Tomatoes", "qty_text": "3 medium" },
      { "name": "Butter", "qty_text": "2 tbsp" }
    ],
    "steps": [
      "Blend tomatoes with aromatics into a smooth puree.",
      "Sauté spices in butter, add puree and simmer until glossy.",
      "Add paneer; adjust seasoning and finish to desired richness."
    ],
    "tips": [
      "Toast spices lightly for depth.",
      "Adjust cream/butter to taste."
    ],
    "image_url": "https://…",                       // optional, may be absent
    "source_attribution": "North Indian restaurant style", // optional
    "youtube_search_url": "https://www.youtube.com/results?search_query=Paneer+butter+masala+recipe"
  }
}

Field schema

recipe.title string

recipe.summary string

recipe.cuisine string, optional

recipe.diet_tags string[]

recipe.servings integer, optional

recipe.prep_time_min integer, optional

recipe.cook_time_min integer, optional

recipe.total_time_min integer, optional (auto-filled if prep+cook available)

recipe.ingredients array of { name: string, qty_text?: string }

recipe.steps string[] (6–12 concise steps preferred)

recipe.tips string[] (0–3 tips)

recipe.image_url string, optional

recipe.source_attribution string, optional

recipe.youtube_search_url string – a ready-to-open YouTube search for the dish
