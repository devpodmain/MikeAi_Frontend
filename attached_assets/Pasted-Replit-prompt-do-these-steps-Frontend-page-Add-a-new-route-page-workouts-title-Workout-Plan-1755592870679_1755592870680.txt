Backend contract (what the frontend will call)

Create & save plan (AI):

POST /workouts/ai

Body:

{
  "ownerId": "<user_id>",
  "profile": {
    "user_id": "<user_id>",
    "sex": "male|female|other",
    "age": 28,
    "height_cm": 178,
    "weight_kg": 78,
    "activity_level": "sedentary|light|moderate|high",
    "training_age_months": 6
  },
  "prefs": {
    "goal": "hypertrophy|strength|fat_loss|general_fitness",
    "days_per_week": 4,
    "session_minutes": 60,
    "equipment": ["barbell","dumbbell","machine"],
    "injuries": "optional text",
    "desired_split": "auto|full-body|upper/lower|push/pull/legs"
  },
  "weeks": 8
}


Response (success):

{ "success": true, "data": { "workoutId": 123, "plan_meta": { "name": "...", "goal": "...", "weeks": 8, "split": "..." } } }


Backend behavior:

Express calls FastAPI /ai/workouts/generate with the same body (minus ownerId).

FastAPI returns a structured plan (days → items).

Express persists: workouts row + workout_items rows.

If an exercise name is unknown, create a minimal exercises row (name only).

Return { workoutId }.

List user plans:

GET /workouts?ownerId=<user_id>

Response:

{ "success": true, "data": [ { "id": 123, "owner_id":"...", "name":"...", "goal":"...", "weeks":8, "created_at":"..." } ] }


Plan items (for expand/view):

GET /workouts/:id/items

Response:

{ "success": true, "data": [ { "id":1,"day_index":0,"order_index":0,"exercise_id":45,"sets":4,"reps":"6-8","rest_sec":120,"notes":null } ] }


(Optional, nicer) Full plan view:

GET /workouts/:id/full returns items joined with exercise names:

{ "success": true, "data": { "workout": {...}, "days": [ { "dayIndex":0,"items":[ { "name":"Barbell Bench Press","sets":4,"reps":"6-8",... } ] } ] } }


FastAPI (AI microservice) you already have

Ensure a route exists: POST /ai/workouts/generate

It must return only JSON shaped like:

{
  "name": "PPL 4-day (Hypertrophy)",
  "goal": "hypertrophy",
  "weeks": 8,
  "days_per_week": 4,
  "split": "push/pull/legs/upper",
  "days": [
    { "dayIndex": 0, "name": "Push", "items": [
      { "exercise": "Barbell Bench Press", "equipment": "barbell", "sets": 4, "reps": "6-8", "rir": "1-2", "restSec": 120, "notes": "" }
    ] }
  ],
  "progression_notes": "double-progression…",
  "warmup_notes": "ramp sets…",
  "deload": "week 8 reduce volume 30–40%…"
}


Express consumes this JSON and saves it.
