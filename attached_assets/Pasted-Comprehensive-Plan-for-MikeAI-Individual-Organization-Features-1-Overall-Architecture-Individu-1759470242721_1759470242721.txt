Comprehensive Plan for MikeAI — Individual + Organization Features
1. Overall Architecture

Individual Mode (current):

AI-powered meal & workout plans (OpenAI LLM)

Personal dashboard (meal/workout generator, regeneration, trackers, AI chat)

Organization Mode (new):

Purchased by gyms/fitness orgs.

Contains:

Org Owner dashboard

Coach dashboards (max 2 by default)

Client dashboards (copy of individual user dashboard but without AI)

Core Difference:

Individual user = full AI integration

Org Clients = manual data entry (no AI calls). Plans created and managed by Org Owner/Coaches.

2. User Roles

Individual User

Already working. No changes.

Org Owner

Create & manage organization profile.

Invite coaches (email invite).

Add/manage clients.

Create meal plans and workout plans (week-based).

Assign plans to clients.

Messaging: org-wide announcements & personal DM to coaches/clients.

Analytics dashboard (client progress, plan adherence).

Coach

Access dashboard under org.

Create/edit weekly meal & workout plans.

Assign to clients.

Track progress of assigned clients.

Messaging: can send announcements (coach → all clients) or personal DMs.

Org Client (Gym Member)

Dashboard copy of individual but manual plans only.

See assigned weekly meal plan & workouts.

Workout tracker (tick off sets/reps, log weights).

Messaging:

View org announcements.

DM with assigned coach or org owner.

3. Dashboard Features (by Role)
A. Individual Dashboard (already live, AI mode)

Upload profile

AI Meal Plan generator

AI Workout generator

Regenerate specific meal/workout

Progress Tracker

Personal Notes

Messaging (future: AI coach chat)

B. Organization Owner Dashboard

Organization Management

Create/Edit org profile (name, logo, subscription plan, gym info).

Invite Coaches (2 seats default).

Add Clients (manually, CSV upload, or invite link).

Plan Management

Create Weekly Meal Plan (7 days, repeat until deleted).

Create Weekly Workout Plan (7 days, repeat until deleted).

Assign plans to 1 or more clients.

Messaging

Community Messages: send announcements visible to all coaches & clients.

Personal Messages: 1-to-1 chat with any coach or client.

Analytics

Client adherence (completed workouts, meal logs).

Coach activity (who assigned plans, last update).

C. Coach Dashboard

View assigned clients.

Create/Edit weekly plans (meal/workout).

Assign/update plans for clients.

Messaging:

Announcements to their clients.

DM with individual clients.

DM with org owner.

Track client progress (manual check-ins, client updates).

D. Client Dashboard (Org Mode)

Read-only Plans

View weekly meal plan.

View weekly workout plan.

Track workouts (mark sets, reps, weights, completion).

Progress Tracking

Daily meal adherence (check meals eaten).

Workout tracker (log reps, sets, weight).

Messaging

See org/community announcements.

DM with assigned coach.

DM with org owner.

4. Workflows
Org Setup

Gym buys Org plan.

Owner sets up org profile.

Owner invites 2 coaches.

Coaches invite/add clients.

Plan Assignment

Coach/Owner creates a weekly meal plan and weekly workout plan.

Assigns to client(s).

Plan repeats every week until deleted/modified.

Clients view plan in dashboard and track completion.

Messaging

Community channel (all org members see).

Personal channel (1-to-1 DM).

Chat stored in DB (message_id, sender_id, recipient_id/org_id, timestamp).

5. Technical Changes Needed
Database

New tables:

organizations (id, owner_id, name, logo, subscription, created_at)

coaches (id, org_id, user_id, role)

clients (id, org_id, user_id, coach_id)

plans_meal (id, org_id, coach_id, week_number, data JSON, repeat_flag)

plans_workout (id, org_id, coach_id, week_number, data JSON, repeat_flag)

assignments (id, plan_id, client_id, type[meal/workout], assigned_at)

messages (id, sender_id, recipient_id/org_id, type[community,dm], body, created_at)

workout_logs (id, client_id, workout_id, sets, reps, weight, completed_at)

meal_logs (id, client_id, meal_id, eaten_flag, logged_at)
